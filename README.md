# Sign-up-Form-Odin

## ENGLISH

### Description
Sign-up form for a fictional service, developed with HTML and CSS as part of The Odin Project's Intermediate HTML and CSS curriculum.

The project focuses on creating a form with custom input fields and basic form validation.

### Technologies
- HTML
- CSS

### Learning Objectives
- Practice creating and structuring HTML forms
- Work with form elements and input types
- Associate labels with input fields
- Style forms using CSS
- Practice CSS selectors and pseudo-classes
- Implement built-in HTML form validation
- Use CSS Flexbox for layout and alignment
- Improve layout structure and visual consistency
- Work with background images and custom fonts
- Recreate a design from a visual reference

## ESPAÑOL

### Descripción
Formulario de registro para un servicio ficticio, desarrollado con HTML y CSS como parte del currículo de HTML y CSS Intermedio de The Odin Project.

El proyecto se centra en crear un formulario con campos de entrada personalizados y validación básica de formularios.

### Tecnologías
- HTML
- CSS

### Objetivos de aprendizaje
- Practicar la creación y estructuración de formularios HTML
- Trabajar con elementos de formulario y tipos de entrada
- Asociar etiquetas a los campos de entrada
- Diseñar formularios utilizando CSS
- Practicar selectores y pseudoclases de CSS
- Implementar la validación nativa de formularios HTML
- Utilizar CSS Flexbox para distribuir y alinear elementos
- Mejorar la estructura y la coherencia visual del diseño
- Trabajar con imágenes de fondo y fuentes personalizadas
- Recrear un diseño a partir de una referencia visual
